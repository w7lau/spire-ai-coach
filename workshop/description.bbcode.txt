[h1]尖塔教练 / Spire AI Coach[/h1]
AI 本回合指导 + 无需 API 的本地整场战斗规划 + 点击执行方案。为了娱乐、研究与比较打法。

[h2]设计目标：尽力兼容不同 Mod[/h2]
尽量从游戏底层读取状态，直接调用原生规则与已加载的 Mod 钩子，按照真实玩法模拟出牌、抽牌、弃牌、消耗、选牌、遗物、能力及敌方行动，减少逐张卡和逐件遗物手写适配。后台省略已识别的展示与动画等待；尚不能保证所有 Mod 自动兼容。

[h2]使用方法[/h2]
[list]
[*]订阅、启动游戏并启用 Mod。不要同时保留手动安装的同一份 Mod。
[*]按 F8 打开／收起面板。左上角入口默认隐藏，战斗面板默认自动展开；在“计算选项 → 高级设置”可关闭“进入战斗自动展开面板”，改为仅手动打开，也可启用左上角入口。F9、F10 没有绑定。
[*]“路线采样”以完整战斗路线组织搜索；“分支扩展”按回合扩展候选。两者都规划到本次战斗结束，共用预算与原生模拟。
[*]按战后净损血比较，包含战中与战后回血；同等损失优先保留药水。药水仅在开启选项时考虑，不是必须喝掉。
[*]可设置并发、尝试次数、搜索时间、回合上限、首次获胜返回及可选补刀／多打牌目标。可查看进度与耗时，或继续优化。
[*]点击“执行方案”才自动出牌，仅限单人战斗。每步校验，偏离预测会停止；Esc 可停止执行。AI 回复不会自动执行。
[*]AI 功能需自行配置 Chat Completions 兼容服务的 URL、模型与 API Key；支持流式回复。点击 AI 分析会把战斗信息发给所填服务商，可能产生费用。本地计算无需 API。
[/list]

主要验证 Windows x64 / 游戏 v0.111.0；界面主要为中文。搜索有预算限制，找到获胜候选不等于已证明全局最优。依赖界面、自定义流程或外部服务的 Mod 可能需要额外适配。

[h2]欢迎一起优化算法[/h2]
欢迎大家通过 Issue / PR 改进搜索、原生模拟、状态复用、公共前缀、并发与有证明依据的剪枝，争取以最快的方式找到最低损失、更接近或可证明最优的完整方案。请在相同输入、预算、目标下比较速度与路线质量；不要用减少预算或漏掉合法操作制造提速。

[h2]English[/h2]
AI advice for the current turn, local planning for the whole battle without an API, and optional click-to-execute plans. Built for fun and experimentation.

The design aims for broad mod compatibility by capturing underlying game state and reusing native rules and loaded mod hooks, rather than hand-coding every card or relic. Background simulation skips recognized presentation work and animation waits. This approach reduces adapters, but does not guarantee support for every mod.

[list]
[*]Press F8 to open/close the panel. The corner button is hidden by default; the panel automatically opens on combat entry. Disable “进入战斗自动展开面板” in advanced calculation settings for manual-only opening, or enable the corner button separately. F9 and F10 are unbound.
[*]Rollout Sampling (路线采样) explores complete battle candidates. Branch Expansion (分支扩展) organizes continuations by turn. Both plan to the end of combat.
[*]Plans prioritize net HP loss after combat, including healing; equal-loss routes prefer preserving potions. Optional potion use does not require drinking every potion.
[*]Configure workers, attempts, search time and turn limits, first-win stopping and optional card goals. Inspect progress and timing or continue optimizing.
[*]Click “执行方案” to execute in singleplayer. State checks stop on divergence; Esc stops active execution. AI text is never executed automatically.
[*]AI requires your own Chat Completions compatible URL, model and key. Clicking AI analysis sends combat data to that provider and may incur charges. Local search does not use an AI provider.
[/list]

Primarily validated on Windows x64 and game v0.111.0. In-game labels are currently Chinese. Budgeted search does not prove global optimality. UI-dependent mods, custom flows and external services may need additional integration.

Contributions are welcome! Help find complete minimum-damage or provably optimal winning plans as quickly as possible, while preserving native and mod rules. Compare identical inputs, budgets and objectives.
