# 可选最终复核

点击本地设置中的「跳过最终复核」可切换开启/关闭。默认关闭；重新启动游戏会恢复默认。它适用于原算法和新算法，药水选项、并发数、无伤提前返回、每路64次/60秒搜索及64回合上限均保持原值。

开启后，后台仍真正执行所推荐路线并完成原生战斗结算；省去的是选出候选后再独立重放一次的复核。0.7.16 起，首次模拟会同步保存逐步状态与完整操作/选牌历史，结果明确标注「已跳过最终复核」，仍可点击「执行方案」，也可按建议手动打牌后续用路线。实际执行逐步核对当前战斗、Mod、原生状态、卡牌实例和完整操作历史，出现偏差立即停止。旧结果或未取得完整记录的结果只供手动查看。

实验对照应记录同一开始状态、完整操作与选牌、最终生命及实际胜负。重新搜索会探索不同候选，单凭两个搜索的耗时或结果不同不能判定复核的错误率。程序目前不自动统计玩家手动对照的偏差；可结合耗时分析中的复核时间、实际操作和日志反馈问题。
