# 本地搜索的默认停止规则

用户于 2026-10-02 补充：如果已经找到无伤路线，且不存在需要额外操作争取的卡牌、遗物或 Mod 奖励，默认可提前停止计算；玩家主动要求继续优化时再搜索更好的路线。

这是搜索器的产品要求。0.5.0 将本地范围扩展到整场战斗，0.7.2 将默认轮数上限从 10 提高到 64，接入原生有界搜索、评分及真实生命损失记录；NativeProbe 仍保留为固定路线对照。奖励机制识别未实现，运行时收益覆盖一律为未知，因此当前版本尚不启用本规则的提前停止。纯策略函数及相关测试不能当作奖励适配已完成。

## 判定边界

默认范围从当前操作点开始，持续到本场战斗胜利及原生胜利钩子结算完成；最多 64 个玩家回合，原生 worker 接受 1–128 的测试/请求上限。到达轮数、操作数或时间上限仅表示部分模拟完成，不具备无伤满意解的提前停止资格，也不表示能获胜。此前真实已经受到的伤害不归零：这里只评估从当前操作点之后的生命损失。

用户于 2026-10-03 澄清目标：优化战后净生命损失，包含战中及战后回血；已经补回来的卖血可以采用。因此 0.7.3 的“无生命消耗”指完整胜利结算后的生命不少于当前操作点的生命，而非过程没有扣血。累计扣血仍显示为过程诊断，不参与正式排名。药水是备用资源，同等净损失优先保留，净损失 0 且不耗药才达到这两个成本轴的下界。格挡足够、敵人意图预览或当前回合 HP 均不能替代完整模拟。

默认提前停止需要同时满足：

1. 路线合法且已经获胜并执行至上述结算边界，恢复与原生状态校验通过。
2. 完整原生胜利结算后的净生命损失为 0，且没有主动消耗药水。
3. 当前局面没有仍值得额外操作的奖励或成长机会；不仅包含立即产出的奖励，还包括永久属性、养牌、击杀触发、遗物计数推进及 Mod 延迟收益。
4. 没有尚未识别、因而无法判断收益的卡牌/遗物/Mod 机制。
5. 玩家没有开启继续优化，也没有尚未满足的额外目标。

不能通过“这条路线没触发奖励”“描述没出现奖励词”或“注册了所有遗物模型”证明第 3、4 条。未知收益状态必须保留为未知，取消这次提前停止资格，继续受时间/节点预算约束的搜索；不是无限计算或拒绝提供已有方案。奖励识别来源、适配覆盖和未识别机制应可诊断。

## 返回与继续优化

满足默认条件时返回“已满足无伤目标，提前结束搜索”，可附预算内找到的路线。该条件是满意解规则，不是伤害最大、资源消耗最小或整场战斗全局最优的证明。默认规则可能在还有可出攻击牌时停止，只要额外操作没有必要收益，且玩家未要求进一步优化。

玩家点击“继续优化”后，不使用上述提前停止条件；以严格匹配当前状态和完整历史的剩余路线为搜索种子，仍按 60 秒预算重新模拟与独立复核。当前正式优先级为胜利、生存、战后净损失、主动用药数、战后生命、最大生命/金币、回合及操作数。达到预算返回已找到且复核的最好结果；只有达到某成本轴的理论下界或完整覆盖有限合法搜索空间后，才能对那一个明确目标声称最优。净损失 0 不代表奖励最大或操作最短。

并行时，调度器收到一条通过完整验证的满意解后，不再派发新分支，协作取消其他计算；等待正在执行的工作进程在安全边界清理，避免中途复用仍有动作或回调的实例。保留已验证的结果。每个进程仍拥有独立战斗状态。

后续实现验证至少覆盖：完整胜利净损失 0 且不耗药、最终未恢复的掉血不可停、卖血后补回可以竞争、耗药胜利仍需比较无药路线、存在成长机会不可停、未知 Mod 收益不可停、继续优化不可停、额外玩家目标未满足不可停、并发取消后的下一次状态恢复一致。奖励覆盖仍未知，本版不启用自动提前停止。
