# 本地搜索的默认停止规则

用户于 2026-10-02 补充：如果已经找到无伤路线，且不存在需要额外操作争取的卡牌、遗物或 Mod 奖励，默认可提前停止计算；玩家主动要求继续优化时再搜索更好的路线。

这是接下来搜索器的产品要求，目前 NativeProbe 仍是固定路线执行与复现验证工具，没有实现搜索、评分或本规则的运行接线。

## 判定边界

默认范围是当前玩家回合及紧随其后的敌方行动，至下一次稳定可操作的玩家阶段；战斗提前胜利则在胜利结算完成处终止模拟。只能声明此范围内无伤，不能推出整场战斗无伤。

“无伤”按期间实际生命损失事件判断，包括出牌代价、反伤和延迟伤害；先扣血再治疗不能仅凭最终生命相同算作无伤。格挡足够、敌人意图预览或当前 HP 均不能替代完整模拟。搜索器需要新增伤害/生命损失轨迹，现有检查点尚不足以证明这一条件。

默认提前停止需要同时满足：

1. 路线合法且已执行至上述结算边界，恢复与原生状态校验通过。
2. 模拟期间没有生命损失。
3. 当前局面没有仍值得额外操作的奖励或成长机会；不仅包含立即产出的奖励，还包括永久属性、养牌、击杀触发、遗物计数推进及 Mod 延迟收益。
4. 没有尚未识别、因而无法判断收益的卡牌/遗物/Mod 机制。
5. 玩家没有开启继续优化，也没有尚未满足的额外目标。

不能通过“这条路线没触发奖励”“描述没出现奖励词”或“注册了所有遗物模型”证明第 3、4 条。未知收益状态必须保留为未知，取消这次提前停止资格，继续受时间/节点预算约束的搜索；不是无限计算或拒绝提供已有方案。奖励识别来源、适配覆盖和未识别机制应可诊断。

## 返回与继续优化

满足默认条件时返回“已满足无伤目标，提前结束搜索”，可附预算内找到的路线。该条件是满意解规则，不是伤害最大、资源消耗最小或整场战斗全局最优的证明。默认规则可能在还有可出攻击牌时停止，只要额外操作没有必要收益，且玩家未要求进一步优化。

玩家开启“继续优化”后，不使用上述无伤提前停止条件；在预算内继续比较收益、击杀、输出和资源消耗等目标。具体目标优先级尚待搜索评分实现明确，不能把讨论中的示例顺序当成已定规则。达到预算返回当前最好结果；只有完整覆盖有限合法搜索空间后，才可对明确定义的目标声称最优。

并行时，调度器收到一条通过完整验证的满意解后，不再派发新分支，协作取消其他计算；等待正在执行的工作进程在安全边界清理，避免中途复用仍有动作或回调的实例。保留已验证的结果。每个进程仍拥有独立战斗状态。

后续实现验证至少覆盖：完整敌方回合无伤可停、回合结束掉血不可停、扣血后回满不可停、存在成长机会不可停、未知 Mod 收益不可停、继续优化不可停、额外玩家目标未满足不可停、并发取消后的下一次状态恢复一致。
