# 本地搜索的预算、目标与停止规则

0.7.12的两个本地按钮共用后台模拟、进度、取消与最终复核，分别选择原算法和回合前缀算法。每路最多64次整场尝试、60秒搜索、64个玩家回合，先达到相应上限即结束；准备和最终复核另计。回合探查另有计数，仍受同一个60秒预算约束。预算或回合上限中断的路线不能当作完整胜利。

## 评分范围

范围从当前操作点开始，到本场胜利及原生胜利钩子结算完成。正式优先级为胜利、生存、战后净生命损失、主动用药数、战后生命、最大生命、金币、回合及操作数。净损失使用计算起点的生命减去完整结算后的生命，最低为0；包含战中与战后回血。过程累计扣血只作诊断，已补回的卖血不单独惩罚。

药水是备用资源，允许用药仍同时探索不用药的路线；相同净损失优先保留药水。净损失0且不耗药只达到这两个成本轴的下界，不证明额外收益最大或回合最短。格挡、意图预览、某回合的血量都不能替代完整原生结算。

## 无伤提前返回

0.7.9按用户后续要求新增默认开启且持久保存的「无伤通关后立即返回（含回血）」：任一路完成胜利、玩家未死亡且战后净损失为0，就停止全部后续搜索，在其他实例安全结束后独立复核最终路线并返回。停止信号属于本次请求与冻结起点，不会影响其他请求或最终复核。两种算法使用同一条件。

目前按明确要求暂不为额外奖励继续搜索：RewardCoverageKnown仍未知，不是奖励机制已经全部适配，也不阻止这个开关生效。已允许的主动用药路线也可以触发提前返回。要继续比较不喝药、更短回合或其他收益，应关闭开关后点击「继续优化」；该入口不会绕过用户保存的停止设置。

原先提出的“无伤、无药、没有额外奖励、没有未知Mod收益时才停止”方案因收益识别未实现而一直无法触发，现已由上述显式开关替代。不再把它写成当前默认行为或声称未知收益已被证明不存在。

## 继续优化与历史去重

「继续优化」沿用刚使用的算法，保留同样的64次／60秒预算。旧算法可将严格匹配当前战斗、模型/Mod、原生状态和完整历史的剩余路线作为探索种子，仍须重新执行。新算法从当前状态生成回合前缀，使用完整操作及原生选择历史去重，预算中断和回合探查不关闭未知后续。

多路分配不同操作/选择分支，每个实例保留独立原生状态。共有前缀仍需重放，去重不代表已有完整战斗检查点。先等所有搜索实例完成或确认停止，再只复核最终候选；失败的候选不能发布为可执行方案。达到预算返回已复核的最佳已知结果，尚未覆盖所有合法未来时不声称全局最优。
