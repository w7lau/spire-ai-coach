# 验证记录

日期：2026-10-02。

## 已执行

- .NET SDK 9.0.318，Release 编译，针对本机游戏 v0.111.0；0 warning / 0 error。
- 33 项核心回归通过：卡牌实例和目标身份、各动作出口、条件回手、未来抽牌条件、JSON 投影、格式归一、过期快照和事件版本、数组边界、API 形状、鉴权、截断、取消与非出牌阶段阻断。
- Windows DPAPI 使用虚构测试 Key 的加密、读取、普通配置不含密钥、取消记住后删除。
- 模型调用使用可控 HTTP 测试替身；不消耗真实 API 额度。
- 作者自查 Prompt → 消费字段 → parser → 纯文本 UI → 当前状态复核，无持久化游戏变化、无旧建议再注入。

## 尚未验证

- 游戏内实际加载与 UI 显示、真实战斗采集、分辨率布局和热键冲突。
- 真实服务商及真实模型的格式稳定性、建议质量、耗时和费用。
- 联机、所有角色、第三方卡牌／Buff／机制 Mod 的运行兼容性。
- 随机洗牌预测、敌人条件分支、多回合模拟；这些没有实现为确定预测能力。

开发时用户已有游戏进程运行，未关闭或接管该进程。编译和测试不能替代实战验证，因此 0.1.0 按实验版交付。

## 手动验证步骤

1. 退出游戏后安装，重启，确认 Mod 列表及日志出现 `[SpireAiCoach] UI mounted`。
2. F8/F10 打开设置，输入自己的服务商配置并保存。
3. 进入战斗，展开快照，对照每个牌堆总数、同名卡数量、当前费用、效果、敌人血量和攻击意图。
4. 发起分析，确认中文建议及目标编号。分析过程中出牌，确认旧请求取消、迟到结果不覆盖新状态。
5. 关闭顶部顺序后核对快照中 draw_order_top_first 为空；清单仍保留完整卡牌。
6. 测试双击、取消、网络不可用、错误 Key、回合结束、退出战斗。
7. 加入目标 Mod，核对自定义文本、动态变量、预览值、读取限制，再评估建议效果。
